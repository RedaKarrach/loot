what would an infostealer take from your laptop? · MIT · github.com/RedaKarrach/loot

What this is for. An infostealer is malware with a shopping list. It does not hack anything. It copies files from a known set of places on your computer, cloud keys, SSH keys, Git logins, the browser's saved passwords, and sends them away. Thirty seconds, and the attacker has everything you can log into. Most of the big breaches of the last few years started exactly like that, on one employee's laptop. loot walks the same shopping list, shows you what a stealer would get and what each item unlocks, grades the result, and gives you a one-line fix per item. Then you fix things and run it again.

It only reads. Nothing leaves your machine. Secrets are never printed in full.

Nine questions, one command each. The output is what loot really prints, run against a planted demo folder where every value is fake.

Press enter, or tap the command line, to run the first one.

END OF TRANSMISSIONRun it on your own laptop.

$ pipx install git+https://github.com/RedaKarrach/loot
$ loot

# nervous? plant a fake home first and scan that
$ python demo/plant.py /tmp/demo-home
$ loot scan --home /tmp/demo-home --system linux

# for scripts, dotfiles repos, laptop onboarding
$ loot scan --json
$ loot scan --fail-on high        # exit 1 if anything high or critical is found

# how the grade works
critical 25 · high 10 · medium 5 · low 1 · info 0, per finding. each category costs at most 40.
100 minus the damage. 90+ A, 75+ B, 60+ C, 40+ D, else F. harsh on purpose.

# what it does not do
- it never opens browser databases or wallet files. it only notices they exist.
- it looks where stealers look, not everywhere. for a whole-repo scan use gitleaks or trufflehog.
- it fixes nothing. every finding has a one-line fix; running them is your call.

# stack
Python 3.11+ · click · rich · no network · tests on Linux, macOS and Windows
